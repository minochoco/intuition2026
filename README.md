# CMD EZ Features

1. Download all files (age_cursor_data.CSV, cursor_sensor.ipynb, feature_param.pkl, mapper.py, model.pkl).
2. Run the mapper.py file.
3. Output will shown be in the Selenium browser (will open automatically).
4. To enable the Acessibility mode features, make sudden and fast movements with cursor (as shown in the video demo) to simulate tremors. Once tremors are detected, prompt will appear to ask to switch to accessibility mode.
5. Press 'Y' to switch to Accessibility mode as prompted.
6. Mulitple numbered tags will appear in the website (in the Selenium browser).
7. Assert the corresponding keys to the numbered tabs labelled next to the option buttons.
8. Accessibility system allows the asserted keys to mimic the action of clicking on these buttons. 

CMD EZ is our product that aims to assist users with motor impairments to reduce their dependence on their cursor when browsing, especially in websites with cluttered menus.
